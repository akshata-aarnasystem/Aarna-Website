04Technical reference

Structured data

Structured data describes the visible page and organisation information in a machine-readable format.

Schema coverage

  • Sitewide: Organization and WebSite.
  • Inner pages: BreadcrumbList with the visible page hierarchy.
  • Services: Service schema on the services overview.
  • About: Organization schema.
  • Contact: ContactPage schema.
  • Resources: WebPage schema; article-specific Article and Person markup should be added when individual authored articles exist.

All structured data must match visible, verified page content. Replace the example domain and confirm company details before production deployment. No testimonials, ratings, prices, certifications or metrics are fabricated by this reference page.
